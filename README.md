\# Ödev Takip Sistemi



Supabase'den sınıf verilerini otomatik olarak Google Drive'a yedekleyen sistem.


\## Setup



1\. GitHub Secrets'e ekle:

&#x20;  - SUPABASE\_SERVICE\_ROLE\_KEY

&#x20;  - GOOGLE\_API\_KEY

&#x20;  - GOOGLE\_DRIVE\_FOLDER\_ID



2\. Workflow her gün 20:00 UTC'de çalışır.
